# Beats Headphones Homepage Clone

A responsive recreation of the Beats Headphones homepage built with HTML, CSS, and JavaScript.

## Live Demo

[View the live Beats Headphones Homepage](https://rina-parsegian.github.io/beats-homepage/)

## About the Project

I built this project to practice recreating a real-world ecommerce homepage from a visual reference and translating an existing design into responsive front-end code.

The goal was to strengthen my ability to structure a complete webpage, recreate layouts and visual elements, build responsive designs, and add basic JavaScript functionality.

## What I Practiced

- Semantic HTML
- Responsive layouts using Flexbox
- Reusable CSS classes and BEM-style naming
- CSS media queries
- Mobile and desktop navigation
- Typography, spacing, and visual hierarchy
- Styling form inputs
- Mobile navigation with JavaScript
- DOM manipulation and event listeners
- Toggling CSS classes for interactive elements
- Preventing background scrolling when the mobile menu is active
- Font Awesome icons
- Git and GitHub workflow

## Technologies Used

- HTML5
- CSS3
- JavaScript
- Font Awesome
- Git
- GitHub
- GitHub Pages

## What I Learned

This project helped me become more comfortable breaking down an ecommerce homepage into individual sections and translating an existing visual design into responsive front-end code.

I gained additional practice using Flexbox to organize layouts, adjusting spacing and alignment, and maintaining consistent typography and styling throughout the page.

I also strengthened my understanding of JavaScript by implementing an interactive mobile navigation menu using DOM selectors, event listeners, and class manipulation. This included toggling the mobile menu and preventing background scrolling when the menu is active.
